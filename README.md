# VeloWin

VeloWin is an independently developed Android application for organizing Windows games and managing verified compatibility runtimes. The Android foundation is being built here, separate from the Winlator codebase.

> Status: early foundation; no Windows execution engine is bundled yet. The interface and runtime installer will clearly disclose launch readiness rather than simulating a running game.

See `docs/ARCHITECTURE.md` for engine integration boundaries after the initial sources are added.
