# Contribuindo com VeloWin

Use PRs pequenos e testáveis. Execute `python3 -m unittest discover -s tests -p 'test_*.py' -v`, a suíte Java `tests/ReleasePolicyTest.java` e `gradle :app:assembleDebug`. Faça descrição de compatibilidade Android, APIs usadas, impacto sobre GPUs Mali/Adreno e licenças dos componentes utilizados.

Não submeta código, assets, firmwares, bibliotecas proprietárias ou binários de outra aplicação sem licença compatível e atribuição. Não habilite execução de jogo enquanto testes de ABI, integridade, gráficos e processo estiverem ausentes. Nunca inclua chaves de assinatura em commits.
